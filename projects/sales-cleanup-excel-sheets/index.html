Project 1: Clean and Analyse a Messy Sales File

Beginner to intermediateAbout 1 to 2 hours (estimate)

Unofficial study resource. Independent practice material, not affiliated with any software vendor.

You have been handed a raw export of one year of orders (2025) from a small fictional retailer. It has real-world problems: duplicate rows, inconsistent spelling in the Region column, and placeholder rows with no quantity. Clean it, then answer questions about it. Work in Excel or Google Sheets. For formulas and pivots, see the Excel study guide or the Google Sheets study guide.

The data

Synthetic data Every file here was generated by a seeded script. It describes no real company, person or sale, and the products and customer IDs are made up.

Download sales_raw.csv (577 data rows). Columns: OrderID, OrderDate, Region, Product, Category, Quantity, UnitPrice, Discount. Dates are written as YYYY-MM-DD. Discount is a fraction (0.10 means 10%).

Revenue for an order is Quantity × UnitPrice × (1 − Discount).

Tasks

  1. Open and inspect. Import or open the CSV. How many data rows are there? Check that OrderDate is recognised as a date and Quantity as a number. Scan the Region column for oddities.
  2. Fix the Region column. Remove stray spaces and make the capitalisation consistent, so there are exactly four regions: North, South, East, West. (Hint: TRIM and PROPER.)
  3. Remove exact duplicate rows. A repeated row is the same order exported twice.
  4. Remove placeholder rows. Delete rows where Quantity is "N/A". They are not real orders.
  5. Add a Revenue column using the formula above, and format it as currency with 2 decimals.
  6. Answer: total revenue; revenue by region (try SUMIFS); revenue by category; the product with the highest revenue; revenue for each month (a pivot table works well); the number of orders that had a discount.
  7. Chart it. Make a column chart of revenue by month with a clear title and axis labels.

Stretch ideas

  • Use XLOOKUP or VLOOKUP to add each product's category from a separate small product table you build yourself.
  • Add a data validation drop-down for Region so bad values cannot be typed in again.
  • Write two sentences for a manager: what the data shows, and one thing you would check next.
