Project 3: Build a Star Schema and DAX Measures in Power BI

IntermediateAbout 2 hours (estimate)

Unofficial study resource. Independent practice material, not affiliated with any software vendor.

Build a small sales model from four tables, write measures for sales and year-over-year change, and design one report page. It practises what the Power BI study guide explains: star schemas, relationships, date tables and CALCULATE.

The data

Synthetic data Every file here was generated by a seeded script. It describes no real company, person or sale, and the products and customer IDs are made up.
FileRoleRows
orders.csvFact table (one row per order): OrderID, OrderDate, CustomerID, ProductID, Quantity, Discount1,000
products.csvDimension: ProductID, Product, Category, UnitPrice12
customers.csvDimension: CustomerID, Region, Segment80
dim_date.csvDate table: one row per day from 2024-01-01 to 2025-12-31731

There is no revenue column on purpose: revenue is Quantity × UnitPrice × (1 − Discount), and the price lives in the product table.

Tasks

  1. Load and set types. Load all four files. Make sure OrderDate and Date are the Date type, Quantity is a whole number, and Discount and UnitPrice are decimals.
  2. Model. Create one-to-many relationships from the dimensions to the fact table: products[ProductID] to orders[ProductID], customers[CustomerID] to orders[CustomerID], and dim_date[Date] to orders[OrderDate]. Keep cross-filter direction Single. Mark dim_date as a date table.
  3. Write three measures (try before you look at the hints below):
    • Total Sales: revenue summed over every order row.
    • Sales LY: Total Sales for the same period in the previous year.
    • YoY %: the percentage change from Sales LY to Total Sales, avoiding division errors.
  4. Build one report page with a card for Total Sales, a line chart of Total Sales by month, a bar chart by Category, and a slicer for Year. Add alt text to each visual.
Show measure hints 
Total Sales =
SUMX (
    orders,
    orders[Quantity] * RELATED ( products[UnitPrice] ) * ( 1 - orders[Discount] )
)

Sales LY =
CALCULATE ( [Total Sales], SAMEPERIODLASTYEAR ( dim_date[Date] ) )

YoY % =
DIVIDE ( [Total Sales] - [Sales LY], [Sales LY] )

SUMX is an iterator, so it can multiply across tables row by row. DIVIDE returns BLANK instead of an error when the denominator is zero or blank.

If your numbers differ by more than a cent, recheck your steps before the data.
