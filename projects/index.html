Reading about a skill is not the same as using it. Each project gives you a dataset to download, a set of tasks, and an answer key so you can check your work.

How to use these projects

  1. Download the data and read the task list.
  2. Work through the tasks without looking at the answer key.
  3. Open the answer key and compare. If your numbers differ, recheck your steps before you doubt the data.

How the answers were checked

Expected values are computed by script from the same files you download, and the test suite recomputes them independently. SQL solutions were run in SQLite. I could not run Excel, Google Sheets or Power BI, so steps in those tools are verified through the numbers they should produce, not by running the tools.

  • Project 1: Clean and Analyse a Messy Sales File: Download a deliberately messy synthetic sales CSV, clean it, then calculate totals, a regional breakdown, a monthly pivot and a chart. Includes an answer key.
  • Project 2: Answer Business Questions with SQL: Load a small synthetic shop database into SQLite and write eight queries: joins, aggregation, a LEFT JOIN anti-join, HAVING and a window function. Includes tested solutions.
  • Project 3: Build a Star Schema and DAX Measures in Power BI: Load four synthetic CSV tables into Power BI Desktop, model them as a star schema with a date table, write three DAX measures and build a one-page report. Includes expected values.
