# SkillPrep — how to edit and deploy

The site is plain static HTML generated by `tools/build.js` (Node 16+, no dependencies).

1. Edit `tools/config.js` — confirm `siteUrl`. The contact form posts to Formspree (see `tools/build.js`); there is no public email address.
2. Edit content in `tools/content/` (`guides.js`, `genai.js`, `lean.js`).
3. Run `node tools/build.js` — regenerates every page, `sitemap.xml` and `robots.txt`.
4. Upload the whole folder to the repo root (GitHub Pages). Keep `.nojekyll`.
5. Re-submit `sitemap.xml` in Google Search Console after deploying.

If you deploy under a sub-path (project site), set `basePath` in config (only the 404 page needs it).

## Practice projects data

`python3 tools/make_data.py` regenerates `projects/data/` (CSV files, `shop.sql`, `answers.json`) from a fixed seed; it needs only the Python standard library. The project pages read `answers.json` at build time, and `node tools/test.js` recomputes every expected value independently and runs the SQL answers in SQLite. After changing the generator, run it, then `node tools/build.js` and `node tools/test.js`.
