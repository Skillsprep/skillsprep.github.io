# SkillPrep — how to edit and deploy

The site is plain static HTML generated by `tools/build.js` (Node 16+, no dependencies).

1. Edit `tools/config.js` — **set `contactEmail` to an inbox you really read**, confirm `siteUrl`.
2. Edit content in `tools/content/` (`guides.js`, `genai.js`, `lean.js`).
3. Run `node tools/build.js` — regenerates every page, `sitemap.xml` and `robots.txt`.
4. Upload the whole folder to the repo root (GitHub Pages). Keep `.nojekyll`.
5. Re-submit `sitemap.xml` in Google Search Console after deploying.

If you deploy under a sub-path (project site), set `basePath` in config (only the 404 page needs it).
