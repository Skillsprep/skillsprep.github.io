Google Sheets Study Guide: Formulas, QUERY and Automation

If you already know Excel, you know most of Google Sheets. This guide focuses on what is different or especially useful in Sheets: array formulas, FILTER and QUERY, LET and LAMBDA, IMPORTRANGE, sharing and Apps Script. For lookups and pivot tables in general, see the Excel study guide. This is an unofficial study aid and is not affiliated with or endorsed by Google. Function behaviour was checked against Google's help pages on 20 November 2026, and Google can change it.

What you will learn

By the end you should be able to:

  • Use SUMIFS, COUNTIFS, IF and XLOOKUP with absolute references and handle common errors
  • Write array formulas with ARRAYFORMULA, FILTER, SORT and UNIQUE, and simplify them with LET and LAMBDA
  • Summarise data with QUERY and with pivot tables
  • Clean data, validate input and import from other spreadsheets with IMPORTRANGE
  • Share safely, protect ranges and automate a task with a macro or Apps Script trigger

Essential formulas

These work as they do in Excel, so this is a quick refresher on what interviewers ask for most.

NeedFormula
Total with conditions=SUMIFS(D2:D, B2:B, "North", C2:C, "Paid")
Count with conditions=COUNTIFS(B2:B, "North", C2:C, "Paid")
Decide between outcomes=IF(D2>=100, "High", "Low")
Look up a value=XLOOKUP(A2, Products!A:A, Products!C:C, "Not found")
Handle an error=IFERROR(XLOOKUP(...), "Check")

XLOOKUP in Sheets. The syntax is XLOOKUP(search_key, lookup_range, result_range, missing_value, match_mode, search_mode). If nothing matches and you give no missing_value, the result is #N/A. match_mode is 0 for exact (the default), 1 for exact or next greater, -1 for exact or next lesser, and 2 for wildcard. Google's own example treats XLOOKUP("Apple", A2:A, E2:E) as equivalent to VLOOKUP("Apple", A2:E, 5, FALSE).

Absolute references. $A$1 locks both column and row, $A1 locks the column, and A$1 locks the row.

Advanced formulas

ARRAYFORMULA shows the results of an array formula across several rows or columns and lets non-array functions work on arrays. Google's examples include ARRAYFORMULA(A1:C1+A2:C2) and ARRAYFORMULA(SUM(IF(A1:A10>5, A1:A10, 0))). Many array formulas expand automatically, and Ctrl+Shift+Enter adds ARRAYFORMULA( for you. Google notes that array formulas cannot be exported.

FILTER keeps the rows where every condition is TRUE:

=FILTER(A2:D, C2:C = "Paid", D2:D > 100)

The conditions must be the same length as the range. You cannot mix row conditions and column conditions in one FILTER, so nest one FILTER inside another. If no rows match, the result is #N/A.

SORT and UNIQUE sort a range and remove duplicate rows, and combine well with FILTER: =SORT(UNIQUE(FILTER(B2:B, C2:C = "Paid"))).

LET names values so each is calculated once. Names are not case-sensitive, cannot be cell references or contain spaces or start with a number, and must be declared before use. Google's example:

=LET(avg, AVERAGE(B2:D2), IF(avg>=4, "Great", IF(avg>=3, "Good", "Poor")))

LAMBDA defines a function from parameters and a formula. Calling it directly looks like =LAMBDA(Salary, Salary*0.3)(1000), which returns 300. The helper functions MAP, REDUCE, BYROW, BYCOL, SCAN and MAKEARRAY take a LAMBDA, for example =MAP(C5:C10, LAMBDA(salary, salary*0.3)).

Named functions save a formula as a reusable function. Use Data > Named functions, or right-click a cell and choose Define named function. They need no code, which is the main difference from an Apps Script custom function. A name cannot match a built-in function or a cell reference, start with a number or contain spaces, and ranges in the definition become absolute.

QUERY: SQL-style summaries in one formula

QUERY(data, query, [headers]) runs a query written in the Google Visualization API Query Language. headers is the number of header rows; if you omit it or use -1, Sheets guesses. Google's help page documents the clauses select, where, group by, pivot and order by. Columns can be referred to by letter (A, B) in a range.

=QUERY(A1:D, "select B, sum(D) where C = 'Paid' group by B order by sum(D) desc", 1)
Keep one data type per column QUERY reads each column using its majority data type. Values of the other type are treated as null, so a text entry in a column of numbers silently disappears from the result.

Clean and import data

NeedTool
Remove extra spaces=TRIM(A2)
Split text into columns=SPLIT(A2, ",")

Stop bad inputData > Data validation, or Insert > Dropdown

Data validation. Add a rule from Data > Data validation, or use Insert > Dropdown to build a list from a range or typed items. By default, input that breaks the rule is rejected; you can choose to show a warning instead.

IMPORTRANGE. The first time you connect two spreadsheets, Sheets shows #REF! with an Allow access prompt. If you do not own the source file, you may need to request access. Google lists limits: 10 MB per request, a refresh about hourly while the file is open, no NOW, RAND or RANDBETWEEN in the imported range (TODAY is fine), and chains or cycles of imports should be avoided.

Pivot tables, charts and dashboards

Select your data and use Insert > Pivot table. In the editor, add Rows, Columns and Values, and use calculated fields (a SUM or a custom formula) when you need a derived measure. Double-clicking a value shows the source rows behind it, and the pivot table refreshes whenever its source data changes. Lookups and pivot concepts are the same as in Excel; see the Excel study guide.

A dashboard in Sheets is simply a sheet that shows summary cells and charts built from pivot tables or QUERY results. Keep source data on its own sheet, build summaries on another, and show only the summary to viewers.

Share and protect your work

RoleWhat it allows
ViewerOpen the file (and download it, unless the owner turns that off)
CommenterOpen and comment
EditorOpen, comment and edit; can share by default unless the owner turns that off
OwnerFull control

General access can be Restricted (only people you add), Anyone with the link, or Public, which can be found through Google Search.

Protected ranges. Data > Protect sheets and ranges lets you protect a sheet or range. You can show a warning (anyone with edit access can still edit after confirming) or restrict who can edit to only you, only your domain, or a custom list.

Not a security measure Google says protection should not be used as a security measure. People with access can still copy, print or export the data. Control access by choosing who the file is shared with.

Automate with macros and Apps Script

Macros. Choose Extensions > Macros > Record macro, do the steps (using absolute or relative references), then save. Sheets writes an Apps Script that you can open in the script editor, and you run the macro from Extensions > Macros.

Simple triggers are functions with reserved names: onOpen, onInstall, onEdit and onSelectionChange (plus doGet and doPost for web apps). They run automatically, but they cannot use services that need authorization, can only change the file they are bound to, do not run in view or comment mode, and must finish within 30 seconds. Changes made by a script or the API, such as Range.setValue(), do not fire them.

Installable triggers can use authorized services and include time-driven triggers (from every minute to once a month), and they run as the person who created them. Create one from Triggers (the alarm clock icon) > Add Trigger, or in code, for example ScriptApp.newTrigger("myFunction").timeBased().everyHours(6).create();

A small example. This onEdit stamps a completion date when the Status column on a sheet named Orders is changed to Done:

function onEdit(e) {
  var range = e.range;
  var sheet = range.getSheet();
  if (sheet.getName() !== "Orders" || range.getColumn() !== 5) return;  // column E = Status
  if (range.getValue() === "Done") {
    sheet.getRange(range.getRow(), 6).setValue(new Date());               // column F = Completed on
  }
}

To use it: open Extensions > Apps Script, paste the function, save, then change a Status cell to Done. Because it is a simple trigger, it only works for edits typed or pasted by a person, not for edits made by another script. The logic of this example was tested against a mock spreadsheet object; it has not been run inside a live Google Sheet.

Practical learning exercises

  • Exercise 1 (SUMIFS). Orders are in A1:D with columns Date, Region, Status, Amount. Total the Amount for the North region where Status is Paid. Solution: 
    =SUMIFS(D2:D, B2:B, "North", C2:C, "Paid")
  • Exercise 2 (XLOOKUP). Look up each ProductID in column A in a Products sheet and return the price in column C, showing "Not found" when there is no match. Solution: 
    =XLOOKUP(A2, Products!A:A, Products!C:C, "Not found")
  • Exercise 3 (ARRAYFORMULA). Fill a Total column for every row at once: Quantity in B, Price in C, leaving blanks for empty rows. Solution: 
    =ARRAYFORMULA(IF(A2:A="", "", B2:B*C2:C))
  • Exercise 4 (QUERY). From the orders table, show each Region with its total Amount for Paid orders, largest first. Solution: 
    =QUERY(A1:D, "select B, sum(D) where C = 'Paid' group by B order by sum(D) desc", 1)
  • Exercise 5 (LET). Scores are in B2:D2. Show "Great" if the average is 4 or more, "Good" if 3 or more, otherwise "Poor", calculating the average once. Solution: 
    =LET(avg, AVERAGE(B2:D2), IF(avg>=4, "Great", IF(avg>=3, "Good", "Poor")))

Interview questions

Try answering aloud before you open each one.

What is the biggest practical difference between Google Sheets and Excel?

Sheets lives in the browser and is built for several people working in one file at once, with sharing roles instead of file copies. Its automation language is Apps Script, where Excel uses VBA. Many everyday formulas are the same, so most of your Excel knowledge carries over.

When would you use QUERY instead of a pivot table or FILTER?

QUERY is useful when you want filtering, grouping, pivoting and sorting in one formula that is easy to read and copy. A pivot table is easier for exploring by drag and drop, and FILTER is simpler when you only need to keep matching rows.

What does ARRAYFORMULA do, and when do you need it?

It makes one formula return results for a whole range and lets functions that normally take single values work on arrays. Many array formulas expand automatically, so you mainly need it to apply a non-array function across a column, such as multiplying two columns row by row.

How is XLOOKUP different from VLOOKUP?

XLOOKUP takes a separate lookup range and result range, so the result column can be left of the key and you do not count column numbers. It defaults to an exact match, has a missing_value argument and can search from the last item.

What are LET and LAMBDA for?

LET names a value or calculation so it is evaluated once and reused. LAMBDA defines a reusable function with parameters. Helpers such as MAP, REDUCE, BYROW, BYCOL, SCAN and MAKEARRAY take a LAMBDA to apply it across data.

What is a named function?

A function you build from Sheets formulas through Data > Named functions, then call by name like any built-in. It needs no code, unlike a custom function written in Apps Script.

How do you bring data from one spreadsheet into another?

Use IMPORTRANGE with the other file's URL and a range string such as "Sheet1!A1:D100". The first time, you click Allow access. Google lists limits, including a 10 MB request size, refresh roughly hourly while the file is open, and avoiding chains and cycles of imports.

How do you stop bad data entering a sheet?

Use Data > Data validation (or Insert > Dropdown) to add a rule. Input that breaks the rule is rejected by default, or you can choose to show a warning instead.

How do sharing roles work?

Viewer can open the file, Commenter can also comment, and Editor can edit and, by default, share. The Owner has full control. General access can be Restricted, Anyone with the link, or Public.

Can you stop people editing part of a sheet?

Yes: Data > Protect sheets and ranges lets you show a warning or restrict editing to you, your domain or a custom list. Google says this is not a security measure, because people with access can still copy, print or export.

What is the difference between a simple and an installable trigger?

Simple triggers such as onEdit run automatically but cannot use services that need authorization, can only change the file they are bound to, and must finish within 30 seconds. Installable triggers can use authorized services, include time-driven triggers, and run as the person who created them.

What is a macro?

A recorded set of steps from Extensions > Macros > Record macro. Sheets turns it into an Apps Script you can view and edit, and you run it from Extensions > Macros. You can record with absolute or relative references.

Practice questions

Question 1 of 20QUERY

Which language does the QUERY function use for its query string?

Why: QUERY runs a Google Visualization API Query Language string against a range. It looks like SQL, but it is its own language with its own clauses.
Question 2 of 20QUERY

In QUERY(data, query, headers), what does the headers argument specify?

Why: headers is the number of header rows in the data. If you leave it out or use -1, Sheets guesses.
Question 3 of 20QUERY

A column passed to QUERY contains mostly numbers and a few text values. What happens to the text values?

Why: Each column should hold one data type. A mixed column is read using its majority type, and values of the minority type are treated as null.
Question 4 of 20FILTER

FILTER finds no rows that meet your conditions. What does it return?

Why: When nothing matches, FILTER returns #N/A. Wrap it in IFERROR if you want a friendlier result.
Question 5 of 20FILTER

You need to keep only certain rows and certain columns with FILTER. What is the rule?

Why: Conditions must all be the same length as the range in one direction. To filter both rows and columns, nest FILTER.
Question 6 of 20XLOOKUP

XLOOKUP finds no match and you did not supply the missing_value argument. What is returned?

Why: missing_value defaults to #N/A. Give it a value such as "Not found" to return that instead.
Question 7 of 20XLOOKUP

Which match_mode value makes XLOOKUP treat * and ? in the search key as wildcards?

Why: 0 is exact match (the default), 1 is exact or next greater, -1 is exact or next lesser, and 2 is wildcard match.
Question 8 of 20XLOOKUP

Which VLOOKUP is equivalent to XLOOKUP("Apple", A2:A, E2:E)?

Why: E is the fifth column of A2:E, and FALSE asks for an exact match. Google's own help page uses this pairing as its example.
Question 9 of 20ARRAYFORMULA

What does ARRAYFORMULA let you do?

Why: ARRAYFORMULA lets one formula return many rows or columns and lets functions that normally work on single values work on arrays.
Question 10 of 20ARRAYFORMULA

What does pressing Ctrl+Shift+Enter do when you finish typing a formula in Sheets?

Why: Google's help page says Ctrl+Shift+Enter (Cmd+Shift+Enter on Mac) adds ARRAYFORMULA( to the start of the formula.
Question 11 of 20LET

What is the main benefit of LET?

Why: LET assigns names to values or calculations, evaluates each once, and lets the final expression reuse them, which also makes long formulas easier to read.
Question 12 of 20LET

Which of these is NOT allowed as a LET name?

Why: Names cannot be cell references, contain spaces or start with a number. They are not case-sensitive and must be declared before they are used.
Question 13 of 20LAMBDA

What does =LAMBDA(Salary, Salary*0.3)(1000) return?

Why: Adding (1000) after the LAMBDA calls it with Salary = 1000, so the result is 1000 * 0.3 = 300.
Question 14 of 20Named functions

How does a named function differ from an Apps Script custom function?

Why: You define a named function from Data > Named functions using ordinary Sheets formulas. Custom functions are written in Apps Script.
Question 15 of 20IMPORTRANGE

You use IMPORTRANGE to pull data from another spreadsheet for the first time and see #REF!. What do you do?

Why: The first connection between two spreadsheets needs permission. The #REF! prompt offers Allow access. If you do not own the source, you may need to request access to it.
Question 16 of 20Pivot tables

You change a value in the source data of a pivot table. What happens to the pivot table?

Why: Google's help page says a Sheets pivot table refreshes when its source data changes. Double-clicking a value shows the source rows behind it.
Question 17 of 20Protection

A protected range is set to Show a warning. Who can edit it?

Why: Show a warning does not block edits; it asks the editor to confirm. Use Restrict who can edit to limit it to you, your domain, or a custom list.
Question 18 of 20Protection

Does Google recommend protected ranges as a security measure?

Why: Google says protection should not be used as a security measure. To keep data private, control who the file is shared with.
Question 19 of 20Apps Script

A script sets a cell with Range.setValue(). Does that fire an onEdit simple trigger?

Why: onEdit runs when a user changes a cell. Script and API changes, such as Range.setValue(), do not trigger it.
Question 20 of 20Apps Script

You want a script to send an email when a cell is edited. Why will a simple onEdit trigger not do this?

Why: Simple triggers run without asking for authorization, so they cannot use services such as Gmail. Installable triggers can, and run under the account of the person who created them.

Preparation checklist

  • Write SUMIFS, COUNTIFS and an XLOOKUP with a missing_value from memory
  • Explain when you need ARRAYFORMULA and how to apply it across a column
  • Use FILTER, SORT and UNIQUE together, and say what FILTER returns when nothing matches
  • Write a QUERY with select, where, group by and order by, and explain the headers argument
  • Describe what happens the first time you use IMPORTRANGE
  • Explain the sharing roles and why protected ranges are not a security measure
  • Describe the difference between a simple and an installable trigger
  • Check Google's help pages for any function you rely on, because behaviour can change
