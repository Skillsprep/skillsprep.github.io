Excel Study Guide: Lookups, Pivot Tables & Core Functions

14 min read 20 Questions Published Sep 5, 2026 Reviewed Oct 18, 2026

Unofficial study resource. Written independently of any exam provider, employer or software vendor.

Excel is one of the most requested skills in office, finance and analyst roles. This guide covers the everyday core — lookups, logical and text functions, and pivot tables — and finishes with practice questions so you can test yourself before an interview or skills test.

Core topics to know

Practical, everyday spreadsheet work rests on these areas:

  • Lookup functions — VLOOKUP, XLOOKUP, INDEX + MATCH
  • Logical functions — IF, IFS, AND, OR, SWITCH
  • Text functions — LEFT, RIGHT, MID, CONCAT, TRIM, TEXTSPLIT (Microsoft 365)
  • Pivot tables — grouping, calculated fields, slicers, and value field settings
  • Conditional formatting — highlight cells rules, color scales, and icon sets
  • Data tools — remove duplicates, text to columns, data validation

VLOOKUP vs XLOOKUP

A classic interview and test question. VLOOKUP only searches the first column of a range and can only return columns to the right. XLOOKUP (Excel 365/2021) searches anywhere and returns from any column:

=XLOOKUP(A2, Sheet2!B:B, Sheet2!C:C, "Not found")
Quick rule If the lookup value may not exist and you want a friendly message instead of #N/A, reach for a function with a built-in if not found argument — that's XLOOKUP (or IFERROR wrapped around VLOOKUP).

Pivot table essentials

A typical scenario: "You have 10,000 rows of sales data and need the total per region per quarter." The right tool is a pivot table, with Region in Rows, Quarter in Columns, and Sum of Amount in Values.

Know the difference between:

  • Sum — default for numeric data
  • Count — counts non-empty cells
  • Distinct Count — requires adding the data to the Data Model

Exact versus approximate matching: what a lookup really does

Most lookup bugs come from not knowing which of two algorithms is running. An exact lookup scans for a value equal to yours and returns the first hit. An approximate lookup assumes the keys are sorted ascending and finds the largest key that is less than or equal to your value. That second behaviour is exactly what you want for banded data such as grades, tax slabs or commission tiers, and exactly what you do not want for employee IDs.

In VLOOKUP the fourth argument chooses the mode. FALSE means exact. TRUE, or leaving the argument out, means approximate. Forgetting it is the classic mistake: on unsorted IDs the formula quietly returns a wrong row instead of an error. Always type the argument explicitly.

Worked example with a tier table in E2:F5:

Min score (E)Grade (F)
0F
50C
65B
80A
=VLOOKUP(B2, $E$2:$F$5, 2, TRUE)

A score of 72 returns B, because 65 is the largest threshold not above 72. A score of 80 returns A, since an equal key counts. The table must stay sorted ascending, and it must start at 0 or every low score returns #N/A.

XLOOKUP (Excel 2021 and Microsoft 365) defaults to exact, which makes the safe choice the lazy choice. Its fifth argument, match_mode, takes 0 for exact, -1 for exact or the next smaller item, 1 for exact or the next larger item, and 2 for wildcard matching. The same grade lookup becomes:

=XLOOKUP(B2, E2:E5, F2:F5, , -1)

The empty fourth argument skips the custom not-found message; the fifth is the match mode.

Interview reasoning If asked why a lookup returned the wrong value rather than an error, check the match mode first, then check for numbers stored as text and stray spaces.

Dynamic array functions and LET, step by step

Before Excel 2021 a formula returned one value per cell. Dynamic array functions return a whole block that spills into neighbouring cells from the cell where you typed the formula. FILTER, UNIQUE, SORT, SORTBY, SEQUENCE and LET all need Excel 2021 or Microsoft 365, so do not build a shared workbook on them if colleagues use Excel 2019 or earlier.

Suppose A2:C9 holds Region, Rep and Amount. To list orders over 5,000 for the East region:

=FILTER(A2:C9, (A2:A9="East")*(C2:C9>5000), "None")

Multiplying the two tests acts as AND, because a row survives only when both give 1. Adding them acts as OR. The third argument is shown when nothing matches; leave it out and you get #CALC!. To get a sorted list of distinct regions:

=SORT(UNIQUE(A2:A9))

The result occupies as many cells as it needs. If something non-empty blocks that area you see #SPILL!, and clearing the obstruction fixes it. To refer to the entire spilled result from another formula, add a hash after the anchor cell, for example E2#.

LET assigns names to intermediate results inside one formula. It makes long formulas readable and avoids repeating an expensive calculation:

=LET(
  sales, FILTER(C2:C9, A2:A9="East", 0),
  total, SUM(sales),
  total / ROWS(sales)
)

Each name is followed by its value; the last argument is the result. Here the East average is computed from a filtered list that is evaluated once.

Compatibility rule Anything that must open cleanly in older versions should use INDEX/MATCH, SUMIFS and COUNTIFS instead of the functions above.

Pivot tables: how they work and why they go stale

A pivot table is a summary built from a snapshot of your source data called the pivot cache. This explains the most common complaint: you edit the source, and the pivot does not change. Right-click the pivot and choose Refresh. Better, make the source an Excel Table (Ctrl+T) before building the pivot, so new rows are included automatically and you avoid a fixed range like A1:F500 that silently misses row 501.

Source data must be tidy: one header row, one record per row, no merged cells, no blank rows, and no subtotal rows mixed in. A blank header gives an error when you create the pivot, and a column mixing text and numbers can make a value field default to Count instead of Sum. When a field you expected to Sum shows Count, look for text-formatted numbers or blanks in that column.

Worked example. Source rows: East/Jan/100, East/Feb/150, West/Jan/80, West/Feb/60. Put Region in Rows, Month in Columns and Amount in Values (Sum). You get East 250, West 140 and a grand total of 390. Now change the value setting to Show Values As, % of Grand Total: East is about 64%, West about 36%. The numbers did not change, only their presentation, which is a distinction worth stating out loud in an interview.

  • Calculated field works on the sum of source fields, so a ratio such as Profit/Revenue is computed from totals, not averaged row by row.
  • Grouping dates into months, quarters or years is done from the right-click menu on a date field.
  • Slicers and timelines are visual filters that can drive several pivots at once when connected to them.
  • GETPIVOTDATA is what Excel inserts when you click a pivot cell from a formula; it keeps the reference valid if the layout changes.

Mistakes that cost marks and how to avoid them

These errors appear again and again in real workbooks and in skills tests.

SymptomLikely causeFix
Lookup returns #N/A though the value is visibleTrailing space, or number stored as text on one sideTRIM, or convert with VALUE or multiply by 1
Formula copied down gives shifting resultsLookup range not anchoredUse $E$2:$F$5
Totals differ from the pivotHidden rows, text numbers, or stale pivot cacheRefresh, check data types
Wrong value, no errorApproximate match on unsorted dataUse exact mode
#REF! after deleting a columnFormula pointed at removed cellsUse Tables or named ranges

For maintainability, prefer Tables with structured references such as Sales[Amount] over raw ranges, because they grow with the data and read like English. Put assumptions like tax rate in one labelled cell and refer to it, rather than burying 0.18 inside twenty formulas. Whole-column references like B:B are convenient and fine in lookups, but many of them across thousands of formulas can slow a workbook; a Table column is both tighter and clearer.

Know when SUMIFS beats a pivot: if you need one number that updates live inside a formula, SUMIFS(Amount, Region, "East", Month, "Jan") is simpler. If you need to explore the data several ways, a pivot is faster.

How to practise and quick glossary

Reading about formulas teaches little; breaking them teaches a lot. A routine that works: take a small dataset of about twenty rows, write each answer two ways (for example XLOOKUP and INDEX/MATCH), then deliberately corrupt the data with a trailing space, a text number and a duplicate key, and predict the result before pressing Enter. Use Formulas, then Evaluate Formula, to watch a nested formula resolve step by step.

Spend time explaining answers aloud. If you can say why approximate match needs sorted data, you understand it; if you can only recite the syntax, you do not yet.

TermMeaning
SpillA formula result that fills several cells automatically
Structured referenceTable-based name such as Table1[Col]
Absolute referenceA reference with $ that does not move when copied
Pivot cacheStored copy of source data a pivot reads from
Volatile functionOne that recalculates on every change, such as TODAY or RAND
Named rangeA label assigned to a cell or range for use in formulas

Practical learning exercises

  • Exercise 1 (Lookups): Download a sample dataset of employees and departments. Write an XLOOKUP formula to pull department names into the employee table, handling missing IDs gracefully with a "Not Found" message.
  • Exercise 2 (Pivot Tables): Use a sales dataset with Dates, Regions, and Amounts. Create a Pivot Table to show total sales per Region, then add a timeline slicer to filter by Q1.
  • Exercise 3 (Logical Functions): Create a grading sheet. Use the IFS function to assign letter grades (A, B, C, F) based on numerical scores, and apply Conditional Formatting to highlight failing grades in red.

Practice questions

Test yourself. Select an answer, then check the explanation.

Question 1 of 20Functions

Cell A2 contains "New York, NY". Which formula extracts just "NY"?

Why: RIGHT(text, 2) returns the last 2 characters. The state code "NY" sits at the end of the string. MID requires a start position and length; TRIM only removes extra spaces.
Question 2 of 20Lookups

Your lookup table has the ID in column D and the name in column C (to its LEFT). Which is the best formula to return the name for ID in A2?

Why: XLOOKUP returns values from a column to the left of the lookup column — VLOOKUP cannot. The "Not found" argument also handles missing IDs gracefully.
Question 3 of 20Pivot Tables

In a pivot table, you want the number of unique customers per product, not the number of orders. What do you need?

Why: Plain "Count" counts rows, so repeat customers are counted multiple times. Distinct Count is only available when the pivot table is based on the Data Model (check "Add this data to the Data Model" when inserting).
Question 4 of 20Logical Functions

You need to categorize sales: under $50 is "Low", $50-$100 is "Medium", and over $100 is "High". Which function is best suited to avoid complex nested IFs?

Why: IFS evaluates multiple conditions sequentially without nesting. SWITCH requires an exact match on a single expression, not ranges like >100.
Question 5 of 20Conditional Formatting

How can you highlight an entire row based on the value in column B?

Why: To highlight a whole row, you must use a custom formula with a mixed reference (like =$B2>100). The absolute column ($B) ensures all cells in the row look at column B, while the relative row (2) adjusts for each row.
Question 6 of 20Lookups

Which function is best for a two-way lookup (finding a value at the intersection of a specific row and column)?

Why: INDEX and MATCH used together can perform two-way lookups efficiently.
Question 7 of 20Data Cleaning

You have a list of names with inconsistent spacing (e.g., ' John Doe '). Which function fixes this?

Why: TRIM removes all spaces from text except for single spaces between words.
Question 8 of 20Logical Functions

Which formula checks if a value in A2 is between 50 and 100?

Why: AND evaluates multiple conditions and returns TRUE only if all are true.
Question 9 of 20Pivot Tables

How do you refresh a Pivot Table when the source data changes?

Why: Pivot Tables do not update automatically; you must manually refresh them.
Question 10 of 20Conditional Formatting

You want to highlight cells in A1:A10 that contain the word 'Urgent'. Which rule type should you use?

Why: The 'Text that Contains' rule is specifically designed for highlighting based on substrings.
Question 11 of 20Formulas

What does the $ symbol do in a formula like =$A$1?

Why: The $ symbol locks the row and/or column reference.
Question 12 of 20Text Functions

If A2 contains 'John Smith', which formula returns 'John'?

Why: FIND locates the space, and LEFT extracts the characters before it.
Question 13 of 20Error Handling

Which function replaces a #DIV/0! error with a custom message like 'Error'?

Why: IFERROR allows you to specify a fallback value if a formula evaluates to an error.
Question 14 of 20Data Validation

How can you restrict users to entering only dates in a specific cell?

Why: Data Validation controls what users can type into a cell.
Question 15 of 20Shortcuts

What is the keyboard shortcut to quickly Autosum a column of numbers?

Why: Alt + = automatically inserts the SUM function for adjacent cells.
Question 16 of 20Charts

Which chart type is best for showing the trend of sales over 12 months?

Why: Line charts are ideal for displaying continuous data over time.
Question 17 of 20Lookups

What is the default match mode for VLOOKUP if the 4th argument is omitted?

Why: Omitting the range_lookup argument defaults to TRUE (approximate match), which requires sorted data.
Question 18 of 20Protection

If you want users to edit cells A1:A5 but lock the rest of the sheet, what is the sequence of steps?

Why: Cells are locked by default, but locking only takes effect when the sheet is protected.
Question 19 of 20Functions

Which function counts cells that meet multiple criteria?

Why: COUNTIFS applies criteria to cells across multiple ranges and counts the number of times all criteria are met.
Question 20 of 20Power Query

What is Power Query primarily used for?

Why: Power Query is Excel's data transformation and preparation engine.
