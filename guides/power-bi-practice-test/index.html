Prepare the data 10 questions

Question 1 of 40Prepare the data

A Customers table and an Orders table share CustomerID. You want each order row to also show the customer's Region. Which Power Query operation do you use?

Correct answer: Merge queries on CustomerID
Merge joins tables side by side on key columns, like a SQL join. Append stacks rows, Group by summarises, and Unpivot turns columns into rows.
Question 2 of 40Prepare the data

A numeric column contains the text "N/A" in some rows, and changing its type to Whole Number produces errors. What is the best fix?

Correct answer: Replace "N/A" with null (or remove those rows), then set the data type
Placeholders that are not valid numbers cause conversion errors. Replace them with null or filter them out first, then change the type.
Question 3 of 40Prepare the data

The source table has 50 columns, but your report uses 8. What is the best practice?

Correct answer: Remove the unused columns in Power Query before loading
Unneeded columns still use memory and refresh time, and hiding them does not remove them. Removing them before the load keeps the model smaller and faster.
Question 4 of 40Prepare the data

A table is too large to import, and users need current values every time they interact with the report. Which storage mode fits?

Correct answer: DirectQuery
DirectQuery leaves the data at the source and queries it as users interact, so it depends on the source's speed. Import must fit in memory and is only as fresh as the last refresh.
Question 5 of 40Prepare the data

You use DirectQuery and add a Power Query step that cannot be translated into a single native query. What is the likely outcome?

Correct answer: An error, or you have to simplify the step so it folds
In DirectQuery, Power Query steps must fold into a single native query. Steps that cannot fold cause errors or have to be simplified.
Question 6 of 40Prepare the data

Query Raw Sales feeds two other queries that shape it differently. You do not want Raw Sales itself in the report model. What do you do?

Correct answer: Build the other two with Reference and turn off Enable load for Raw Sales
A referenced query starts from the original's output, so there is one source of truth. Turning off Enable load stops the staging query from becoming a model table.
Question 7 of 40Prepare the data

A table has a Metric column (Revenue, Cost, Profit) and a Value column. You want Revenue, Cost and Profit as separate columns. Which transformation fits?

Correct answer: Pivot column
Pivot turns the values of one column into new column headers. Unpivot does the opposite.
Question 8 of 40Prepare the data

You want to change a file path or server name for every query without editing each one. What should you create?

Correct answer: A Power Query parameter
Parameters hold values such as paths and server names that queries refer to, so you change them in one place.
Question 9 of 40Prepare the data

Which Power Query view shows the percentage of valid, error and empty values in each column?

Correct answer: Column quality
Column quality shows valid, error and empty values as percentages. Column distribution shows how often values occur, with distinct and unique counts. By default, profiling uses only the first 1,000 rows.
Question 10 of 40Prepare the data

Power Query blocks a merge of a workbook marked Private with an SQL Server source marked Organizational. Which setting is responsible?

Correct answer: Data source privacy levels
Privacy levels (Private, Organizational, Public) control whether data can flow between sources when queries are combined, to stop sensitive data leaking.

Model and DAX 12 questions

Question 11 of 40Model and DAX

Which relationship is the usual choice between a dimension table and a fact table?

Correct answer: One-to-many, with the dimension on the 'one' side
Dimension tables hold unique keys (the 'one' side) and fact tables hold many matching rows (the 'many' side).
Question 12 of 40Model and DAX

Which DAX function returns a value from the 'one' side table into a calculated column on the 'many' side?

Correct answer: RELATED
RELATED follows an existing relationship to fetch a column value from the related table.
Question 13 of 40Model and DAX

In a star schema, where should a customer's Region column live?

Correct answer: In the Customer dimension table
Descriptive attributes belong in dimension tables, which filter and group the facts. Repeating them on every fact row only bloats the model.
Question 14 of 40Model and DAX

You must analyse sales by order date and by ship date in the same visual at the same time. What does Microsoft recommend?

Correct answer: A separate date table for each role, each with its own active relationship
Only one relationship between two tables can be active. A separate table per role allows simultaneous filtering; the cost is a little duplicated storage.
Question 15 of 40Model and DAX

What does the calculated table Date = CALENDARAUTO() create?

Correct answer: A date table covering the dates found in the model
CALENDARAUTO generates a table of dates that covers the dates in the model and extends as new data loads. Relate it to your facts and mark it as a date table.
Question 16 of 40Model and DAX

You need a Total Amount that responds to slicers and is not stored row by row. What do you create?

Correct answer: A measure
A measure is evaluated at query time in the current filter context and stores only its formula.
Question 17 of 40Model and DAX

Inside a calculated column, CALCULATE([Total Sales]) is used with no filter arguments. What does it do?

Correct answer: Converts the current row context into a filter context
With no filter arguments, CALCULATE performs context transition: the current row becomes filters on the model.
Question 18 of 40Model and DAX

Which measure gives each product's share of total sales?

Correct answer: DIVIDE ( [Total Sales], CALCULATE ( [Total Sales], ALL ( 'Product' ) ) )
ALL removes the product filters inside CALCULATE, so the denominator is the grand total while the numerator keeps the row's context. The second option always returns 1, the third hard-codes one category, and the fourth divides by a row count.
Question 19 of 40Model and DAX

Which expression returns the previous month's sales?

Correct answer: CALCULATE ( [Total Sales], DATEADD ( 'Date'[Date], -1, MONTH ) )
DATEADD with a negative number shifts dates back by that many intervals. SAMEPERIODLASTYEAR moves back a year, TOTALMTD is month-to-date, and DATESYTD returns dates rather than a value.
Question 20 of 40Model and DAX

Inventory on hand can be added across warehouses but should not be added across days. What kind of measure is this?

Correct answer: Semi-additive
A semi-additive measure can be summed across some dimensions but not across time, for example by showing the closing balance of a period.
Question 21 of 40Model and DAX

You need YTD, prior-year and YOY% variations for many measures without writing a separate measure for every combination. Which feature helps?

Correct answer: Calculation groups
A calculation group defines each variation once as a calculation item that uses SELECTEDMEASURE() as a placeholder. You create them in Model view, and they apply to explicit measures only.
Question 22 of 40Model and DAX

Which Power BI Desktop tool records how long each visual takes and lets you copy its DAX query?

Correct answer: Performance Analyzer
Performance Analyzer logs a duration for each visual, split into DAX query, visual display and other (plus DirectQuery time), and can copy the query so you can run it in DAX query view.

Visualize and analyze 10 questions

Question 23 of 40Visualize and analyze

Which visual best shows the relationship between two numeric measures across many items?

Correct answer: Scatter chart
A scatter chart plots one measure against another for each item, which makes correlations and outliers easy to see.
Question 24 of 40Visualize and analyze

Which feature saves a report's current view, such as filters and which visuals are visible, so a button can return to it?

Correct answer: Bookmarks
A bookmark captures a report state that users can return to, often through buttons, which is the basis of simple report navigation.
Question 25 of 40Visualize and analyze

A Year slicer on page 1 should keep the same selection on pages 2 and 3. What do you configure?

Correct answer: Sync slicers
Sync slicers keep a slicer's selection consistent across the pages you choose.
Question 26 of 40Visualize and analyze

Clicking a bar chart should not filter one particular table on the same page. Which feature do you use?

Correct answer: Edit interactions
Edit interactions lets you choose, for each visual, whether selecting another visual filters it, highlights it or does nothing.
Question 27 of 40Visualize and analyze

You want margin cells to turn red automatically when they fall below a target. Which formatting feature do you use?

Correct answer: Conditional formatting
Conditional formatting applies colours or icons based on rules or values, so the formatting updates as the data changes.
Question 28 of 40Visualize and analyze

Hovering over a bar should show a small chart for that item. What do you create?

Correct answer: A report page used as a custom tooltip
A custom tooltip is a report page configured as a tooltip, which appears when users hover over a visual.
Question 29 of 40Visualize and analyze

Which practice improves the accessibility of a report?

Correct answer: Add alt text to visuals and set a logical tab order
Screen-reader users rely on alt text and a sensible tab order. Never use colour alone to carry meaning, and keep contrast high.
Question 30 of 40Visualize and analyze

A matrix has a Year > Quarter > Month hierarchy. A user turns on drill down and clicks the 2026 column. What happens?

Correct answer: The visual moves to the quarters of 2026 and stays on the same page
Drill down moves down a hierarchy within the same visual. Drillthrough is the feature that opens another page with filters applied.
Question 31 of 40Visualize and analyze

You want to draw an average or target line on a chart. Where do you add it?

Correct answer: The Analytics pane, as a reference line
The Analytics pane adds elements such as constant and average lines, forecasts and error bars to supported visuals.
Question 32 of 40Visualize and analyze

Which task is best suited to a paginated report?

Correct answer: Printing one invoice per page with repeating headers and footers
Paginated reports are designed for printing and sharing, give exact control of the layout, and print every row of a table across as many pages as needed.

Manage and secure Power BI 8 questions

Question 33 of 40Manage and secure Power BI

Which workspace role can only view and interact with items, and is useful for enforcing row-level security?

Correct answer: Viewer
Viewers cannot create or edit content. Row-level security applies to Viewers, while Admin, Member and Contributor can edit the model and so bypass it.
Question 34 of 40Manage and secure Power BI

Where are row-level security roles defined, and where are users added to them?

Correct answer: Roles in Power BI Desktop; members in the Power BI service
You define roles and DAX filters in Desktop (Modeling, Manage roles) and publish. You cannot assign users in Desktop; you add them to the roles in the service.
Question 35 of 40Manage and secure Power BI

Which function is commonly used in a dynamic row-level security filter to return the signed-in user's sign-in name in the service?

Correct answer: USERPRINCIPALNAME()
In the service, USERPRINCIPALNAME() returns the user's UPN, which you compare with a column such as ManagerEmail in a mapping table.
Question 36 of 40Manage and secure Power BI

A user belongs to two RLS roles: one allows the West region and the other the East region. Which rows do they see?

Correct answer: Both West and East
Roles are additive, so a user in several roles sees the union of the rows each role allows.
Question 37 of 40Manage and secure Power BI

Which data source needs an on-premises data gateway for scheduled refresh in the Power BI service?

Correct answer: A SQL Server database on the company's private network
A gateway lets the service reach data it cannot access directly over the internet, such as sources on a private network.
Question 38 of 40Manage and secure Power BI

On shared capacity with Power BI Pro, what is the maximum number of scheduled refreshes per day for a semantic model?

Correct answer: 8
Pro on shared capacity allows 8 scheduled refreshes a day. Premium per user and Premium or Fabric capacity allow 48.
Question 39 of 40Manage and secure Power BI

You edited a report in the workspace after publishing an app. When do the app's users see the change?

Correct answer: After you select Update app
The workspace is the staging area. Changes are not live in the app until you update it.
Question 40 of 40Manage and secure Power BI

Which endorsement can be applied only by reviewers that the Power BI administrator has authorised?

Correct answer: Certified
Anyone with write permission on the workspace can promote content. Certification needs the admin to enable it and to designate reviewers.

After the test: a study checklist

  • For each missed question, reread its explanation and find the matching section in the study guide
  • Be able to explain Import vs DirectQuery, and why a step that cannot fold is a problem in DirectQuery
  • Practise writing CALCULATE, DIVIDE and time-intelligence measures from memory
  • Know which workspace roles bypass row-level security, and where roles are defined and assigned
  • Open Microsoft's current PL-300 study guide to confirm the skills measured before you sit the exam
